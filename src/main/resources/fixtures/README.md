# 离线案例包：热转折案 —— DSC 基线、相变积分与扫描历史审阅器

材料组把同一样品（ALLOY-X batch 7）的加热与冷却 DSC 序列放进同一份样品履历，
为玻璃化、结晶与熔融事件建立可重算的基线与积分。本目录是该案的全部领域材料，
不是通用表格：每个文件都是一台模拟量热仪（SIM-DSC-250）的原始输出。

## 仪器输出（原始表示，导入时不做规范化）

| 文件 | 覆盖的边界情形 |
| --- | --- |
| `runA_heat.csv` | 加热段：玻璃化转变（约 75 °C 台阶）、冷结晶放热峰（约 135 °C）、熔融吸热峰（约 225 °C），等间隔温度网格 |
| `runB_cool.csv` | 冷却段：约 180 °C 结晶放热峰；与加热段同履历但绝不混用 |
| `runC_misnamed_cooling.csv` | 反向热流 + 文件名误导：文件名写着 cooling，数据实际升温；表头 `sign_convention: exo_up`，吸热峰朝下 |
| `runD_nonuniform.csv` | 非等间隔温度网格（0.5/1.5 K 交替），且有一个无法转换的 `OVERLOAD` 单元格，原样保留并附诊断 |
| `runE_overlap.csv` | 重叠转折：约 140 °C 与 152 °C 两个吸热峰之间回不到基线 |
| `runF_cycles.csv` | 循环段切换：单一文件内 HEAT→COOL→HEAT 三段 |

## 分别存档的输入

- 仪器输出：上表六个 CSV，原始文本整体入库。
- 样品质量：`mass_mg: 8.42`（初称），剧本第二步复称为 8.61 mg，产生新的质量版本。
- 扫描速率：`scan_rate_K_per_min: 10`，以原始字符串存档，派生层才解析。
- 气氛：`atmosphere: N2 50 mL/min`，原样存档。
- 温度标定：`calibration_id: CAL-2026-03`，系数与不确定度单独建档。
- 用户选定切线：每条切线区间独立成行，带作者与版本号。

## 剧本（scenario.json）

1. 初始导入并核对六类输入分别存档。
2. 参数修订：质量 8.42 → 8.61 mg，所有按质量归一化的派生（J/g）过期，温度类派生保持有效。
3. 局部源数据改动：仅移动熔融峰左切线区间，依赖图只重算受影响节点。
4. 互相冲突的人工决定：两位审阅者从同一版本分别采纳 linear-chord 与 area-sigmoid 基线，系统保留双方候选并登记可解决的冲突。
5. 空区间检验：在 runD 数据范围之外选切线区间，被拒绝并留下机器可读的诊断事件。

## 坐标基准与单位

温度为 °C（仪器坐标基准，导入时保留），热流为 mW，扫描速率 K/min，
焓变派生为 J/g（= mJ/mg）。无法转换的值（如 `OVERLOAD`）留在原位置并附诊断，
不为画图而丢弃。
