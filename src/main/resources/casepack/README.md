# 热转折案：DSC 基线、相变积分与扫描历史审阅器（离线案例包）

材料组把同一样品（sample-A，淬火 PET 粒料）的加热与冷却 DSC 序列放进同一份样品履历，
为玻璃化、结晶和熔融事件建立可重算的基线与积分。

## 初始版本（导入即得）
- `instrument/heat1.csv`：第 1 循环升温段，表头 `direction=exo-up`，非等间隔温度，
  含玻璃化(~65C)、结晶放热(~112C)、熔融吸热(~152C)。
- `instrument/cool1.csv`：第 1 循环降温段，表头 `direction=endo-up`（与升温段相反的约定，
  反向热流），结晶放热峰方向随之反转。
- `instrument/heat2_endo_guess.csv`：第 2 循环升温段，表头缺少 direction（unknown），
  文件名含 `endo` 字样作为陷阱——吸放热方向不能靠文件名猜测；
  含重叠转折（冷结晶与熔融尾部重叠）与 80-90C 空区间。
- `sample.json` / `calibration.json` / `tangents.json`：样品质量版本、温度标定、
  用户选定切线，分别存档。
- `events_def.json` / `baselines.json`：热事件区间与并列基线候选。

## 重放脚本（events.jsonl）
1. 参数修订：质量 mass-v1 -> mass-v2，所有归一化派生（J/g）过期。
2. 局部源数据改动：curve-heat2 换用 `instrument/heat2b.csv`，只有依赖它的派生重算。
3-6. 一次人工决定 + 一次互相冲突的人工决定（同一版本上两人各选一条基线），
   冲突可解决，未选候选保留。
7. 空区间检验：evt-empty 区间内无采样点，派生留空并附诊断。
8. 循环段切换检验：把升温事件绑到降温段的请求被拒绝并留档。

## 不变量
- 吸放热方向只来自仪器表头；文件名提示仅记录在案。
- 升温/冷却段不混用；多个合理基线保留差异；质量修订使全部归一化派生过期。
- 每个派生值带稳定身份（der:*），导出/删除/导入后身份、顺序、来源关系不变。
